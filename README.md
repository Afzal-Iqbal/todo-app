Daily To-Do App

This is a basic web application that gives the users an interface where they can easily set and organize their tasks of the day. Its simple and uncluttered design allows the user to input new task, check the task as complete, and delete the completed tasks. It also uses local storage to make the to-do list remain even after the browser has been refreshed or closed.

Features:

Add Tasks: Writing a new task is possible using the keyboard by simply entering it in the input field and pressing ‘Enter’ on the keyboard or by the mouse using the ‘Add’ button.
Mark Tasks as Complete: The user can complete the task by clicking on the task.
Remove Tasks: Eliminate tasks from the list by clicking the cross [X] that is located next to each of the tasks.
Local Storage: These lists are stored locally on the device so even if you exit the browser you can revisit it with your progress saved.
Clean and Modern Design: A current app design ensures that it has a more updated interface and more focus on the readability of the content.
Technologies Used:

HTML: For placing the content in organization and in proper arrangement on the web page.
CSS: To create the look and feel of the applicaiton.
JavaScript: In terms of user interactions, DOM manipulation and local storage management.
To Run the App:

Clone this repository.
This means that let the index.html file open on a web browsing program.
